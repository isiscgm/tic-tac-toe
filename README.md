## 💢 Funcionalidades

- Partidas para dois jogadores.
- Tabuleiro interativo pensado em matriz 3x3.
- Cadastro dos nomes dos jogadores.
- Placar de vitórias.
- Identificação de vitória e empate.
- Interface gráfica moderna.
- Reinicialização de partidas.

## 🛠️ Tecnologias

- Java
- Java Swing
- Java AWT
- IntelliJ IDEA

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/isiscgm/tic-tac-toe.git
```

Abra o projeto no IntelliJ IDEA e execute a classe `src/view/TelaJogo.java`.
